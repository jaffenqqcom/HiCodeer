HiCodeer is a fork of zed, a high performance code editor. HiCodeer runs on HarmonyOS.
Run ./script/bundle-ohos  to build the HAP in HarmonyOS PC or OpenEuler Virtual mechine.
Run hicodeerd command in HarmonyOS terminal to use the full function. hicodeerd is the bridge program to make the Hicodeer can run the programs installed by brew
To use the lsp, you need to install lsp program in the HarmonyOS terminal, exp rust-analyzer and so on.
